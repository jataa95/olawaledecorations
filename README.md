# Olawale Decorations Ltd.

Website for Olawale Decorations Ltd. (Interior & Exterior Designing, Abeokuta). Built with Next.js 16 and Tailwind CSS 4.

```bash
npm install
npm run dev
```

Business details (phone, WhatsApp, email, address, socials) live in `data/site.js`. The contact form sends to WhatsApp or email once one of those is filled in.
